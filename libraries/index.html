Libraries, side by side

Using a library on one platform? Find what teams use for the same job on Android, iOS, Flutter and React Native, and copy the dependency line.

Shows libraries that have a From entry, next to their To counterpart.

How to read this page
  • Each entry is one job (for example image loading). It lists the library commonly used for that job on each platform, with a link to its official page.
  • The install line is shown without a version: a Gradle group:artifact, a Swift Package Manager repository URL, an npm i package, a flutter pub add package or a NuGet id. Check the library's own page for the current version and setup steps.
  • The Compose, Views, SwiftUI and UIKit tags show which UI toolkit a library targets. Entries without a tag are not tied to one toolkit.
  • Built in notes name what the platform already provides, so you may not need a library.
  • Deprecated and Archived badges reflect the status recorded when the data was last updated. Libraries listed side by side do the same job but are not drop-in API replacements.
  • Translate shows a two-column table: pick the platform you know in From and the one you are moving to in To.
